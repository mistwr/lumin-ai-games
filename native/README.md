# LUMIN AI GAMES — Android nativo (protótipo isolado)

Este módulo inicia uma aplicação nativa Android com Kotlin e Jetpack Compose, sem modificar a APK Capacitor existente.

## Objetivo
Biblioteca local, seleção de ROMs, ecrã Descobrir e motor Libretro após auditoria da licença GPL-3.0 e dependências do Omnidroid.

## Estado
UI nativa inicial e seletor de ROMs; ainda **não** incorpora emulador, capa automática, catálogo remoto nem saves. O Omnidroid não foi copiado.

## Compilação
Abrir a pasta `native` no Android Studio recente, instalar SDK 35, compilar `assembleDebug`. Não é a app final.
